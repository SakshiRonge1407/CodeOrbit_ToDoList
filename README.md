# TaskFlow To-do List App
**Stack:** HTML, CSS, vanilla JavaScript. No installation needed.

## Run
Open `index.html` in a modern browser or use VS Code Live Server.

## Features
- Add, edit, delete and complete tasks
- High, normal and low priorities
- All / Active / Completed filters
- Summary counters and clear-completed action
- Saves tasks in browser localStorage
- Responsive design

## Limitations
Tasks stay in the current browser profile and are not synced across devices. Clearing browser storage removes them.
